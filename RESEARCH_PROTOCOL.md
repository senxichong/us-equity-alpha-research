# Research protocol

SURVIVORSHIP-BIASED PROTOTYPE UNIVERSE

1. Never randomly split time-series data. Use chronological train/validation/test boundaries; overlapping forward labels require appropriate purging/embargo.
2. Every feature must be available at its prediction timestamp. Separate publication/availability time from accounting period or event effective date.
3. A target may use future data only as the target; never leak it into features, screening or preprocessing. State prediction horizon and execution convention.
4. Preprocessing may not use future periods or future cross-sections. Fit learned transforms on permitted training observations only.
5. Do not use the test period for tuning.
6. Save a resolved config, raw snapshot hashes, dependency versions, code version and randomness settings for every experiment.
7. Retain failed experiments and failed data downloads with their causes.
8. Do not perform unlimited tuning based on test results. Predeclare selection criteria and record the number of attempts.
9. Every backtest result must be generated by versioned code and identifiable inputs. No hand-entered performance metrics.
10. Disclose known data bias prominently, including survivorship bias, missing delistings, universe reconstruction uncertainty, retrospective revisions and ticker reuse.

Current phase is data feasibility only. `factors/`, `evaluation/`, `models/`, and `backtest/` intentionally contain no implementation. A Phase 2 decision requires a separate instruction. `point_in_time_universe` is blocked until a vetted historical membership and security identity provider is integrated; configuration flags alone cannot bypass the block.

Phase 2 addendum: the user has separately authorized a validated prototype panel. Every resulting dataset and report must disclose `survivorship_biased=true`; a dataset PASS is conditional on that scope. Failed validation must result in explicit quarantine or a disclosed nontradable missing row under predeclared rules. Do not select quality thresholds after seeing downstream factor or performance results. Do not infer historical industry, size or identity from current metadata. Phase 2 ends at the dataset/report gate without computing factors or executing later phases.
